# 디스커버리 노트 정리

## 언제 쓰나

영업 미팅·전화 직후, 손으로 받아적은 메모나 녹취 전사본을 넘겨받았을 때.
"이 미팅 노트 정리해줘", "디스커버리 정리", "미팅 내용 요약" 같은 요청에 해당한다.

## 원칙

**추측해서 채우지 않는다.** 이 스킬의 가치는 빈칸을 만들어내는 데 있는 게 아니라,
*무엇이 아직 확인되지 않았는지*를 드러내는 데 있다. 메모에 근거가 없는 항목은
반드시 `미확인`으로 남기고, 그럴듯한 값을 지어내지 않는다. 영업 담당자가
다음 미팅에서 물어야 할 것을 알아야 하기 때문이다.

**고객이 쓴 표현을 보존한다.** 과제를 우리 제품 용어로 번역하지 말고 고객이 말한
그대로 적는다. "재고가 안 맞아서 월말마다 이틀씩 밤새요"를 "재고 관리 최적화 니즈"로
바꾸는 순간, 나중에 제안서를 쓸 때 근거가 사라진다.

**숫자에는 출처를 붙인다.** 고객이 말한 수치인지, 담당자의 추정인지, 우리 계산인지
구분한다.

## 출력 형식

```
## <고객사명> — <미팅일자>

**참석자**
- 고객: <이름/직책> (발언 비중이 큰 순서)
- 우리: <이름>

**고객이 말한 과제**
- <고객 표현 그대로> — (영향: 정량 수치가 언급됐다면 여기)

**현재 상태**
- 지금 어떻게 처리하고 있는지, 어떤 도구를 쓰는지

**예산**       : <금액 / 범위 / 미확인>
**도입 시점**   : <시기 / 미확인>
**의사결정 구조**: <결재선, 확인된 부분만>
**챔피언**      : <우리를 밀어줄 사람 / 미확인>
**경쟁**        : <언급된 타사 / 없음 / 미확인>

**다음 액션**
- [ ] <누가> <무엇을> <언제까지>

**확인 못한 것**
- <다음 미팅에서 물어야 할 항목>
```

## 주의

- 담당자 이름·연락처·계좌·주민번호 등이 메모에 섞여 있으면 [[customer-data-handling]]의
  규칙을 따른다.
- 미팅 참석자가 여러 명이면 누가 말했는지 구분해서 적는다. 실무자의 불만과
  결재자의 우선순위는 다른 무게를 갖는다.
