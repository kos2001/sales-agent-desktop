# 시장동향 정리

## 언제 쓰나

주간·월간 시황 정리, 가격 협상 전 배경 파악, 고객이 "요즘 시장 어때요"라고 물을 때,
판매계획을 세우기 전 전제를 만들 때. 개별 고객사 조사는 [[account-brief]]가 맡는다.

**이 스킬은 단기 시황 — 이번 달 무엇이 움직였는가를 다룬다.**
시장의 구조적 크기(TAM/SAM)는 [[market-sizing]]이 맡는다. 둘을 섞으면
한 달 등락으로 시장 규모를 논하게 되고, 그 문서는 둘 다에 못 쓴다.

## 이 스킬의 태도

시황 자료는 숫자가 많을수록 그럴듯해 보이고, 그래서 가장 위험하다.
이 스킬의 규칙은 하나다 — **모든 숫자에 출처와 기준 시점을 붙인다.**
붙일 수 없으면 그 숫자는 쓰지 않는다.

그리고 **관측과 해석을 섞지 않는다.** "3월 수입 물량 12% 감소"는 관측이고,
"그래서 4월에 가격이 오를 것"은 해석이다. 해석에는 해석이라고 쓴다.

## 볼 것

**1. 수요측**
- 전방 산업의 가동률·생산 계획. 우리 수요는 결국 그쪽에서 나온다.
- 고객사의 재고 수준. 고객이 재고를 쌓고 있으면 다음 분기 주문은 준다.
- 계절성. 지금의 변화가 추세인지 매년 같은 시기의 반복인지 구분한다.

**2. 공급측**
- 경쟁사의 증설·감산·정기보수 일정
- 수입 물량과 그 출처
- 신규 진입자

**3. 가격**
- **호가와 실거래가를 구분한다.** 공표된 가격과 실제 체결된 가격은 다르다.
  어느 쪽인지 밝히지 않은 가격 정보는 반쪽이다.
- 스프레드(우리 판가 - 원료가)의 방향

**4. 원가·외부 변수**
- 원재료 가격, 환율, 물류비·운임
- 규제, 관세, 정책, 인증 요건의 변화

**5. 대체재**
- 우리 제품을 대신할 수 있는 것의 가격이 어떻게 움직이는가

## 출력 형식

```
## 시장동향 — <대상 시장> / <기준일>

**요약 (3줄)**
- <가장 중요한 변화 하나>
- <두 번째>
- <세 번째>

### 관측
| 항목 | 이번 | 직전 | 방향 | 출처 / 기준일 |
|---|---|---|---|---|
| 수요 | | | ↑↓→ | |
| 공급 | | | | |
| 가격(실거래) | | | | |
| 원재료 | | | | |

### 해석 (추론)
- <관측에서 무엇을 읽을 수 있는가. 근거가 된 관측을 지목한다.>

### 우리 판매에 미치는 영향
- 물량: <늘려야 하나 줄여야 하나 — [[supply-allocation]]으로 연결>
- 가격: <협상에서 쓸 논거 / 방어해야 할 지점>
- 고객: <영향을 크게 받는 고객사>

### 확인되지 않은 것
- <숫자를 못 구한 항목과, 누구에게 물어야 하는지>
```

## 규칙

**"우리 판매에 미치는 영향"을 빼지 않는다.** 그게 없으면 뉴스 요약이지 영업 자료가
아니다. 시황을 읽는 이유는 이번 달에 무엇을 다르게 할지 정하기 위해서다.

**추세를 한 점으로 말하지 않는다.** 한 달 수치의 등락은 추세가 아니다.
최소 3개 시점을 보고, 못 봤으면 "단기 변동일 수 있음"이라고 쓴다.

**전망을 단정하지 않는다.** "오를 것이다"가 아니라 "이 조건이 유지되면 오르는 방향"으로
쓰고, 그 조건을 명시한다. 틀렸을 때 무엇이 틀렸는지 알 수 있어야 한다.

**고객사에서 들은 정보는 출처를 익명화한다** — "A사 구매팀" 수준으로 적고,
[[customer-data-handling]] 원칙을 따른다. 다른 고객에게 그대로 옮기지 않는다.
