# 분기 고객 리뷰 (QTR / QBR)

## 언제 쓰나

주요 고객과의 분기 사업 리뷰 준비, 반기·연간 리뷰,
공급사(제조사)와의 분기 리뷰. 정기 회의 자료 작성과 후속 관리.

## QBR이 실패하는 방식

대부분의 QBR은 **우리가 잘한 것을 발표하는 자리**가 되어 끝난다.
그러면 고객은 다음 분기부터 참석 직급을 낮추고, 결국 실무 미팅이 된다.

QBR이 유지되려면 고객이 **이 자리에 와야 얻는 것**이 있어야 한다.
그건 실적 보고가 아니라 **결정과 약속**이다.

그래서 구성은 이 순서를 지킨다.

1. **지난 분기 약속 결산** — 우리가 한 약속, 지킨 것과 못 지킨 것
2. **숫자** — 실적, 품질, 납기. 나쁜 것을 먼저
3. **문제와 조치**
4. **다음 분기 계획과 상호 실행 항목**

**1번을 맨 앞에 두는 것이 핵심이다.** 지난 약속을 결산하지 않고 시작하는 리뷰는
약속이 누적되지 않으므로 매 분기 처음부터 시작한다.

## 준비

**1. 지난 회의록에서 약속을 뽑는다**
우리 약속과 고객 약속을 **둘 다** 뽑는다. 고객이 하기로 한 것
(사양 확정, forecast 제출, 승인 진행)도 결산 대상이다.
못 지킨 것은 사유와 함께 먼저 적는다.

**2. 숫자를 맞춘다**
- 물량·매출: 계획 대비 실적 — [[sales-execution-tracking]]
- **납기 준수율**: 우리가 약속한 날짜 대비 실제 납품
- **품질 지표**: 클레임 건수, 불량률, 처리 소요일 — [[rma-handling]]
- 고객 내 점유율 추정과 근거

**우리 숫자와 고객 숫자가 다를 수 있다.** 특히 납기 준수율은 기준일
(출하일인지 도착일인지, 최초 약속일인지 변경된 날짜인지)에 따라 완전히 달라진다.
**기준을 회의 전에 맞춘다.** 회의장에서 기준 논쟁이 시작되면 나머지는 다 날아간다.

**3. 고객의 관심사에서 출발한다**
고객의 사업 상황(신제품 일정, 생산 계획 변경, 그들의 시장)이 먼저이고
우리 실적은 그 안에서의 이야기다. [[account-brief]]와 [[market-trend-brief]]에서 가져온다.

**4. 결정받을 것을 고른다**
QBR은 실무에서 안 풀리는 것을 푸는 자리다.
연간 물량 약정, 단가 계약 갱신, 신규 승인 진행, 재고 운용 방식 변경 —
**결정권자가 그 자리에 있을 때만 가능한 것**을 준비한다.

**5. 로드맵과 변경 예고**
EOL 예정, PCN 예정, 신제품 계획을 **여기서 미리 알린다** —
[[eol-management]], [[pcn-management]]. 마감이 임박해서 통지하면
고객은 대응할 시간이 없고, 그 경험이 다음 거래를 결정한다.

## 출력 형식

```
## 분기 리뷰 — <고객사> / <분기>

### 1. 지난 분기 약속 결산
| 약속 | 주체 | 기한 | 결과 | 사유 |
|---|---|---|---|---|
*(못 지킨 것을 위에 놓는다)*

### 2. 실적
| 지표 | 계획/목표 | 실적 | 전분기 | 비고 |
|---|---|---|---|---|
| 물량 | | | | |
| 매출 | | | | |
| 납기 준수율 | | | | 기준: <출하일/도착일> |
| 클레임 | | | | |

### 3. 문제와 조치
| 문제 | 영향 | 원인 | 조치 | 완료 시점 |
|---|---|---|---|---|

### 4. 다음 분기
**고객 계획**: <생산·신제품 일정, 수요 전망>
**우리 계획**: <공급, 재고, 신규 제안>
**변경 예고**: <EOL / PCN / 신제품>

### 5. 상호 실행 항목
| 할 일 | 주체 | 기한 |
|---|---|---|

### 결정 요청
| 안건 | 필요한 결정 | 없으면 생기는 일 | 기한 |
|---|---|---|---|
```

## 규칙

**나쁜 숫자를 먼저 놓는다.** 고객은 이미 알고 있다. 우리가 먼저 꺼내면
관리되고 있다는 신호이고, 고객이 먼저 꺼내면 숨겼다는 신호다.

**상호 실행 항목으로 끝낸다.** 우리 할 일만 적힌 QBR은 보고이지 리뷰가 아니다.
고객 측 항목이 하나도 없으면 그 관계는 일방적이라는 뜻이고, 그것 자체가 신호다.

**숫자 기준을 사전에 합의한다.** 특히 납기 준수율과 점유율.

**가격·물량을 그 자리에서 확약하지 않는다.** 결정권자가 있어도 조건은
[[pricing-strategy]]와 [[contract-operations]] 절차를 거친다.

**다른 고객의 실적·조건을 비교 자료로 쓰지 않는다.** 익명화해도 추정 가능한
비교는 넣지 않는다 — [[customer-data-handling]].
