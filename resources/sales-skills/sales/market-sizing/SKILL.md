# 시장 규모 산정 (TAM/SAM/SOM)

## 언제 쓰나

신규 시장·지역 진입 검토, 사업계획과 투자 검토, 지역·용도별 우선순위 결정,
"이 시장 얼마나 되나", "우리가 가져올 수 있는 게 얼마나 되나".

단기 시황(가격·수급의 이번 달 변화)은 [[market-trend-brief]]가 맡는다.
이 스킬은 **구조적인 크기**를 다룬다. 둘을 섞으면 이번 달 등락으로 시장 규모를
논하게 된다.

## 이 스킬의 산출물은 숫자가 아니라 계산 과정이다

시장 규모는 반드시 틀린다. 중요한 것은 **틀렸을 때 어디가 틀렸는지 알 수 있는가**다.
그래서 모든 가정에 이름·값·출처를 붙이고, 나중에 값 하나만 바꿔 다시 계산할 수 있게
남긴다. 근거 없이 제시된 하나의 숫자는 이 스킬의 실패다.

## 1단계 — 정의를 먼저 고정한다

계산 전에 세 범위의 경계를 문장으로 쓴다. 대부분의 시장 규모 논쟁은
계산이 아니라 정의가 달라서 생긴다.

- **TAM (전체 시장)**: 이 제품군이 쓰이는 전체 수요. 우리 제약은 아직 반영하지 않는다.
- **SAM (유효 시장)**: TAM에서 **우리가 실제로 팔 수 있는 범위**만 남긴 것.
  아래 필터를 적용한다.
- **SOM (획득 가능 시장)**: SAM 중 정해진 기간(보통 3년) 안에 현실적으로 확보 가능한 몫.
  캐파와 영업 인력이 상한이다.

**대상 기간, 지역, 제품 규격, 단위(물량인지 금액인지)를 함께 적는다.**

## 2단계 — TAM에서 SAM으로 깎는 필터

각 필터마다 얼마가 빠지는지 수치로 남긴다. "대략 절반"은 필터가 아니다.

- **규격·품질**: 우리 제품이 못 맞추는 등급의 수요
- **인증·규제**: 인증이 없어 못 파는 지역·용도 (취득 가능하면 SOM이 아니라 향후 SAM)
- **물류 반경**: 운임을 얹으면 경쟁력이 없어지는 거리 — [[territory-prospecting]]
- **기존 계약**: 장기 계약으로 묶여 있어 당장은 열리지 않는 물량
- **자가 생산(captive)**: 고객이 직접 만들어 쓰는 몫. 시장 통계에는 잡히지만 우리 몫이 될 수 없다.
- **최소 물량·설비 제약**: 우리가 대응 못 하는 주문 형태

## 3단계 — 두 가지 방식으로 계산하고 대조한다

**하향식 (top-down)**
공표된 시장 통계·협회 자료·수입 통계에서 출발해 우리 정의로 잘라 내려온다.
빠르지만 원 통계의 정의가 우리와 다르다는 위험이 늘 있다.

**상향식 (bottom-up)** — 이쪽이 더 믿을 만하다
```
대상 고객 수 × 고객당 연간 사용량 × 단가
```
후보 고객을 실제로 세어 올라간다. 실물 제품이라면 **금액보다 물량(톤·개) 기준으로
먼저 계산하고 단가를 나중에 곱한다.** 가격은 분기마다 변하지만 수요 물량은
구조적이라 가정이 오래 산다.

**두 결과가 3배 이상 벌어지면 계산이 아니라 정의가 틀린 것이다.**
숫자를 절충하지 말고 정의로 돌아간다.

## 4단계 — 감도 분석

결과를 가장 크게 흔드는 가정 두세 개를 골라, 그 값을 ±30% 움직였을 때
결과가 어떻게 변하는지 적는다. 이게 있어야 어떤 가정을 먼저 검증할지 정해진다.

## 출력 형식

```
## 시장 규모 — <제품 / 지역 / 기준 연도>   단위: <톤 또는 금액>

### 정의
| 범위 | 경계 (문장으로) | 규모 |
|---|---|---|
| TAM | | |
| SAM | | |
| SOM (3년) | | |

### TAM → SAM 필터
| 필터 | 제외량 | 근거 / 출처 |
|---|---|---|

### 계산
**하향식**: <출처> → <계산> = <결과>
**상향식**: <고객 수> × <고객당 사용량> × <단가> = <결과>
**차이**: <배수> → <차이의 원인 또는 "정의 재검토 필요">

### 핵심 가정
| 가정 | 값 | 출처 | 확실성 |
|---|---|---|---|

### 감도
- <가정 A> ±30% → SOM <범위>

### 이 숫자로 할 수 있는 말 / 할 수 없는 말
```

## 규칙

**TAM으로 목표를 세우지 않는다.** 계획의 근거는 SOM이다.
TAM은 "이 방향에 갈 만한 크기가 있는가"를 보는 숫자이지 목표가 아니다.
TAM을 목표 근거로 쓴 계획은 [[sales-plan]]에서 신규분 과다로 반드시 무너진다.

**시장 보고서 숫자를 그대로 옮기지 않는다.** 보고서의 제품 정의는 대개 우리보다 넓다.
어떤 정의였고 우리 정의로 어떻게 잘랐는지를 함께 쓴다.

**출처 없는 숫자를 쓰지 않는다.** 못 구한 값은 "가정"이라고 표시하고 근거를 적는다.
가정임을 표시한 숫자는 쓸 수 있지만, 출처인 척하는 숫자는 못 쓴다.

**단위와 기준 연도를 모든 표에 적는다.** 물량과 금액이 섞이고 연도가 섞이는 것이
이 문서에서 가장 흔한 사고다.
