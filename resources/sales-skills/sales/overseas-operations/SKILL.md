# 해외 법인 지원 · 해외 출장 운영

## 언제 쓰나

해외 법인의 영업 지원 요청 처리, 본사–법인 간 역할 조정,
법인 실적 점검, 해외 출장 계획과 사후 정리.

여러 지역에 걸친 **고객** 관리는 [[global-account-management]]가 맡는다.
이 스킬은 **우리 조직 쪽 — 해외 법인과 출장 운영**을 다룬다.

## 1. 본사와 법인의 경계를 먼저 정한다

해외 법인 지원에서 생기는 마찰은 대부분 **누가 무엇을 결정하는지가
불분명해서** 생긴다. 요청을 받을 때마다 판단하지 말고 경계를 문서로 둔다.

| 항목 | 본사 | 법인 | 비고 |
|---|---|---|---|
| 가격 결정 한도 | | | 초과 시 본사 승인 |
| 신규 고객 개설 | | | |
| 여신 한도 설정 | | | |
| 재고 보유 결정 | | | |
| 공급사 대응 창구 | | | |
| 계약 체결 권한 | | | |

**법인이 자체 결정할 수 있는 범위를 넓게, 그러나 명확하게 둔다.**
모든 건을 본사 승인으로 걸면 법인은 현지에서 속도를 잃고,
경계가 흐리면 사후에 문제가 된다.

## 2. 법인 운영 점검에서 볼 것

**실적**
법인별 물량·매출·마진. **본사 기준과 법인 기준의 차이를 확인한다** —
통화, 인식 시점(선적 기준 vs 도착 기준), 내부 거래 정산 방식에 따라
같은 거래가 다른 숫자로 잡힌다. 기준을 맞추지 않은 비교는 무의미하다.

**재고**
법인 보유 재고의 연령과 건전성. **현지 재고는 본사에서 잘 안 보인다.**
부진 재고가 법인에 쌓이는 것이 흔한 패턴이다 — [[inventory-management]].

**여신과 회수**
현지 고객의 결제 지연, 여신 한도 초과, 회수 이력.
현지 관행이라는 이유로 방치된 미회수 채권이 없는지 본다.

**규정 준수**
현지 노동·세무·수출입 규정, 대리인·컨설턴트 계약.
**현지 관행과 본사 규정이 충돌하면 본사 규정과 법을 따른다.**
특히 선물·접대와 대리인 수수료는 [[business-courtesy]]의 판정을 거친다 —
반부패 법규는 국외 행위에도 적용된다.

**정보 공유**
법인이 아는 시장 정보가 본사로 오는가. 한 방향으로만 흐르는 관계는
오래 못 간다 — [[market-trend-brief]]에 현지 정보를 넣는다.

## 3. 해외 출장 운영

**목적에서 역산한다.** "가 봐야 안다"는 목적이 아니다.
목적이 정해져야 만날 사람, 준비할 자료, 성공 기준이 정해진다.

| 목적 | 성공 기준의 예 |
|---|---|
| 신규 고객 개척 | 만나기로 한 곳과 실제로 만난 곳 — [[territory-prospecting]] |
| 기존 고객 관계·리뷰 | 합의된 상호 실행 항목 — [[qbr-review]] |
| 문제 해결 | 원인 규명과 조치 합의 — [[rma-handling]] |
| 법인 점검·지원 | 확인 항목과 결정 사항 |

**준비**
- 일정을 **고객 확정 순서로** 짠다. 확정되지 않은 미팅을 전제로 항공을
  잡으면 빈 날이 생긴다
- 현지 공휴일·셧다운 확인. 이 확인 하나로 출장 전체가 무의미해지기도 한다
- 비자·초청장·입국 요건, 현지 이동 시간(체감보다 훨씬 길다)
- 반출 자료의 **보안 등급 확인** — 노트북·샘플·도면의 반출 가능 여부
- 법인 동행자 지정. 현지 담당 없이 가는 미팅은 후속이 끊긴다
- 비용은 사내 규정 한도 안에서 사전 승인

**출장 중**
- **매일 기록한다.** 여러 곳을 돌면 사흘 뒤에는 어느 고객이 무슨 말을 했는지 섞인다
- 약속한 것을 그 자리에서 적는다 — 특히 가격·납기·샘플 제공
- 확답하지 않는다. "확인 후 회신"으로 돌린다

**출장 후 — 여기가 실제 성과가 갈리는 곳**
- **귀국 후 3일 안에** 보고와 후속 조치. 늦으면 현지에서 만든 온도가 식는다
- 사내 보고: [[sales-meeting-report]]의 업무보고 형식
- 고객 회신: [[followup-email]]
- 프로파일 갱신: [[customer-profile]]
- 샘플·자료 발송 약속은 기한을 박아 담당에게 넘긴다

## 규칙

**현지 관행을 규정보다 앞에 두지 않는다.** 특히 선물·접대, 대리인 수수료,
계약 절차. 현지에서 통용된다는 것이 근거가 되지 않는다.

**법인 실적을 기준 정렬 없이 비교하지 않는다.** 통화·인식 시점·내부 거래
정산 방식을 맞춘 뒤에 비교한다.

**출장 중 가격·납기를 확약하지 않는다.** 현지에서 한 말은 되돌리기 더 어렵다.

**결과를 3일 안에 기록한다.** 기록되지 않은 출장은 비용만 남는다.

**반출 자료와 샘플의 보안·통관 요건을 사전에 확인한다.**
고객 정보가 담긴 자료의 국외 반출은 [[customer-data-handling]] 기준을 따른다.
