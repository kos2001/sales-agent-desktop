# 신규수요 창출

## 언제 쓰나

기존 고객만으로 목표가 안 나올 때, 재고가 남아 새 판로가 필요할 때,
신제품·신규격의 판매처를 찾을 때, 특정 고객 의존도를 낮춰야 할 때.

## 세 갈래로 나눠 본다

섞어 놓으면 후보가 많아 보이지만 실행 계획이 안 나온다. 셋은 난이도가 다르다.

**1. 신규 고객 (같은 용도)** — 가장 빠르다
우리 제품을 이미 쓰는 용도에서, 지금 경쟁사·수입품을 쓰는 곳.
필요한 것: 왜 바꿔야 하는지의 근거 하나.

**2. 신규 용도 (기존 제품)** — 가장 크지만 가장 느리다
우리 제품이 안 쓰이던 용도로의 전개. 물성 검증, 샘플, 양산 승인이 붙는다.
필요한 것: 시간. 계획에 넣을 때 리드타임을 정직하게 잡는다.

**3. 신규 지역·채널** — 물류와 조건이 변수다
운임, 최소 물량, 대리점·총판 구조. 파트너를 거치는 건이면 누구에게 쓰는 자료인지를
먼저 정한다 — 파트너용과 최종 고객용은 담을 수 있는 정보가 다르다.
**이 갈래는 [[territory-prospecting]]이 따로 맡는다.** 지역은 운임·인증·현지 경쟁이
먼저 판정되어야 후보 목록이 의미를 갖기 때문에, 여기서 다루지 않고 넘긴다.

## 절차

**1. 우리가 이기는 조건을 먼저 정의한다**
후보 목록부터 만들면 안 된다. **우리 제품이 확실히 우위인 조건**을 두세 개 쓴다 —
특정 물성, 납기, 소량 대응, 품질 편차, 근접 물류.
그 조건이 중요한 곳만이 진짜 후보다. 조건을 못 쓰겠으면 그것이 첫 번째 결론이다.

**2. 그 조건에 맞는 후보를 세운다**
조건에서 후보로 내려온다. "큰 회사라서"는 근거가 아니다.

**3. 진입 장벽을 확인한다** — 이걸 빼면 계획이 전부 낙관이 된다
- 승인 절차: 샘플 → 시험 → 양산 승인. 각 단계에 몇 개월이 걸리는가.
- 인증·규격: 산업 인증, 고객사 자체 규격, 등록 요건
- 기존 공급사와의 계약 잔여 기간
- 최소 물량·설비 제약

**4. 물량과 시점을 추정한다**
추정치에는 **반드시 "추정"이라고 쓰고 근거를 붙인다** (생산능력 기준인지,
동종 고객 실적 기준인지). 첫 매출이 이번 기간에 잡히는지 다음 기간인지 구분한다.
후보 물량의 합이 시장 크기를 넘지 않는지 대조한다 — [[market-sizing]]의 SOM이 상한이다.

**5. 첫 접촉 가설**
누구에게, 무엇을 들고, 무엇을 물을 것인가. 실제 첫 미팅은 [[discovery-notes]]로 넘긴다.

|---|---|---|---|---|---|---|---|
| 신규고객 | | | (추정) | | | | |
| 신규용도 | | | (추정) | | | | |

- <승인 리드타임이 짧아 기간 내 실현 가능한 후보>

## 규칙

**승인 리드타임을 무시한 계획을 쓰지 않는다.** 신규 용도는 대개 이번 분기 숫자가
아니다. 그것을 [[sales-plan]]의 신규분에 넣으면 계획 전체가 틀어진다.
언제 매출이 되는지를 후보마다 명시한다.

**기존 고객 잠식을 확인한다.** 새 후보가 우리 기존 고객의 고객이면
신규 수요가 아니라 자리 바꾸기다. 그런 경우 반드시 짚고, 관계 위험을 함께 쓴다.

**추정 물량을 사실처럼 쓰지 않는다.** 후보 단계의 숫자는 전부 추정이고,
표시 없이 합산되는 순간 존재하지 않는 파이프라인이 만들어진다.

**공개된 정보와 들은 정보를 구분한다.** 다른 고객사에서 들은 정보를 근거로 쓸 때는
출처를 익명화하고, 그 고객에게 불리하게 쓰지 않는다 — [[customer-data-handling]].
