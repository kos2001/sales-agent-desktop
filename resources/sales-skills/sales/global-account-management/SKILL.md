# 다국적 고객(MNC) 관리

## 언제 쓰나

본사와 해외 사업장이 나뉜 고객 관리, 글로벌 단가 협상, 지역 간 조건 차이 조정,
설계처와 구매처가 다른 고객 대응. 우리 쪽 해외 법인이 함께 붙는 건 —
[[overseas-operations]].

## MNC가 어려운 이유는 하나다

**결정하는 곳과 사는 곳이 다르다.**

설계는 본사 연구소에서 하고, 승인은 본사 품질에서 내고, 구매는 지역 본부가 하고,
실제 발주와 납품은 각국 공장에서 나온다. 이 넷이 다른 나라에 있는 경우가 흔하다.

여기서 생기는 사고는 정해져 있다.
- 발주하는 공장만 관리하다가 **본사에서 경쟁사로 사양이 바뀐 것을 뒤늦게 안다**
- 지역마다 다른 가격이 고객 내부에서 비교되어 **가장 낮은 가격이 기준이 된다**
- 여러 지역 담당이 같은 고객에 각자 접근해 **회사가 하나의 목소리를 못 낸다**
- 한 지역에서 발굴했는데 다른 지역에서 매출이 나 **기여 인정이 분쟁이 된다**

이 스킬은 그 넷을 예방하는 순서로 되어 있다.

## 1. 의사결정 지도를 만든다

**어느 기능이 어느 거점에 있는가**를 표로 만든다. 이게 없으면 나머지는 못 한다.

| 기능 | 거점·법인 | 담당 | 우리 측 담당 | 접촉 여부 |
|---|---|---|---|---|
| 설계·사양 결정 | | | | |
| 품질 승인 | | | | |
| 구매 계약·단가 | | | | |
| 발주·납기 | | | | |
| 대금 결제 | | | | |

**한 번도 접촉하지 못한 기능을 맨 먼저 말한다.**
특히 **설계·사양 결정 거점을 접촉하지 못한 MNC 고객은 위험으로 분류한다.**
발주는 계속 들어와도, 다음 세대 제품에서 조용히 빠질 수 있다.

## 2. 가격 일관성 규칙을 먼저 정한다

**MNC 고객은 지역 간 가격을 비교한다.** 반드시 한다고 가정하고 시작한다.

- 지역별 가격 차이는 **설명 가능한 근거**만으로 만든다:
  물류비, 관세, 현지 세금, 결제 조건, 물량, 재고 부담.
  협상력 차이로 생긴 격차는 반드시 문제가 된다
- **글로벌 기준가와 지역 조정분**의 구조로 관리한다.
  각 지역 가격이 독립적으로 정해지면 통제가 불가능해진다
- 고객이 "다른 지역은 더 싸다"고 할 때를 대비해 **차이의 근거를 미리 문서화**한다
- 마크업 구조는 [[markup-policy]], 협상 준비는 [[pricing-strategy]]

## 3. 하나의 목소리를 만든다

- **글로벌 담당(리드)을 지정한다.** 누가 이 고객에 대해 최종적으로 말하는가
- 지역 담당들 사이의 정보 공유 주기를 정한다.
  각자 아는 것을 합치지 않으면 고객이 우리보다 우리를 잘 안다
- 고객에게 나가는 조건·일정·로드맵은 리드를 거쳐 정렬한다
- 분기 리뷰는 지역별로 하되, 연간은 본사와 한다 — [[qbr-review]]

## 4. 기여 인정 규칙을 사전에 정한다

발굴 지역과 매출 지역이 다를 때의 규칙을 **일이 생기기 전에** 정한다.
사후에 정하면 반드시 분쟁이 된다.

- 설계 승인을 따낸 지역과 발주가 나는 지역의 인정 비율
- 실적 집계 기준(선적 기준인지 계약 주체 기준인지)
- 이 규칙은 [[sales-target-setting]]의 지역별 목표 배분과 맞물린다

## 5. 지역별 실무 차이를 기록한다

같은 고객이라도 지역마다 다르다: 인도 조건, 결제 조건과 통화, 검사 절차,
포장·라벨 요건, 현지 인증, 공휴일과 셧다운 일정.
[[customer-profile]]을 지역별로 나눠 관리한다.

## 규칙

**지역 간 가격 차이는 근거로만 만든다.** 설명할 수 없는 격차는
고객이 발견하는 순간 전 지역 가격이 최저가로 수렴한다.

**한 지역의 조건을 다른 지역 담당에게 공유할 때도 범위를 지킨다.**
같은 고객 그룹이라도 우리 내부 공유와 고객에게 나가는 자료는 다르다 —
[[customer-data-handling]].

**설계 거점을 접촉하지 못한 상태를 정상으로 두지 않는다.**
매 리뷰마다 이 항목을 다시 올린다.

**글로벌 조건을 지역 단위에서 확약하지 않는다.** 한 지역에서 한 약속이
전 지역에 적용되는 것이 MNC 협상의 기본 구조다. 조건은 리드를 거친다.

**고객사 정책이 선물·접대를 금지하는 경우가 많다.** 지역 관행으로 판단하지 말고
[[business-courtesy]]의 1단계 판정을 반드시 거친다.
